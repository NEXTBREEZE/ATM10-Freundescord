## 🧭 Installation über CurseForge

### Voraussetzungen

-   [CurseForge-App
    herunterladen](https://www.curseforge.com/download/app)
-   Minecraft Java Edition
-   Die Modpack-ZIP aus dem Google-Drive-Link oben
-   Genügend freier Speicherplatz für Modpack und Spieldateien

### Schritt 1 -- Modpack herunterladen

1.  Öffne den [Modpack-Download auf Google
    Drive](https://drive.google.com/file/d/1MsmILQTGb-HtgIqOAQKhj1j4V66O_MsC/view?usp=sharing).
2.  Lade die ZIP-Datei auf deinen Computer herunter.
3.  Merke dir den Speicherort, zum Beispiel den Ordner **Downloads**.

**Die ZIP-Datei nicht entpacken.**

### Schritt 2 -- CurseForge öffnen

1.  Starte die **CurseForge-App**.
2.  Wähle **Minecraft: Java Edition** aus.
3.  Öffne **Meine Modpacks**.
4.  Klicke oben auf **Importieren**.

### Schritt 3 -- ZIP-Datei auswählen

1.  Wähle im Fenster **Import Profile** links **Import Profile .zip**.
2.  Klicke auf **Choose .zip file**.
3.  Öffne den Ordner, in dem du die ZIP-Datei gespeichert hast.
4.  Wähle die Modpack-ZIP aus und bestätige.

Der Importweg entspricht deinen Screenshots: **Meine Modpacks →
Importieren → Choose .zip file**.

### Schritt 4 -- Import abwarten

CurseForge importiert das Profil und richtet die Modpack-Instanz ein.
Warte, bis der Vorgang abgeschlossen ist. Je nach Computer und
Dateigröße kann das einige Zeit dauern.

### Schritt 5 -- Minecraft starten und verbinden

1.  Öffne das importierte Profil **ATM10 -- FREUNDESCORD**.

2.  Klicke auf **Spielen** und warte, bis Minecraft gestartet ist.

3.  Öffne den Mehrspieler-Modus.

4.  Füge einen Server hinzu oder wähle **Direkt verbinden**.

5.  Gib diese Server-Adresse ein:

    ``` text
    5.175.177.15
    ```

6.  Verbinde dich mit dem Server.

## 🛠️ Fehlerbehebung

### Die ZIP-Datei lässt sich nicht herunterladen

-   Öffne den Google-Drive-Link erneut.
-   Prüfe, ob die Datei für Personen mit dem Link freigegeben ist.
-   Wenn Google Drive eine Vorschau zeigt, nutze das Download-Symbol.
-   Stelle sicher, dass der Download vollständig abgeschlossen wurde.

### CurseForge findet die ZIP-Datei nicht

-   Prüfe, ob du im Dateiauswahlfenster den richtigen Ordner geöffnet
    hast.
-   Wähle die ZIP-Datei direkt aus.
-   Entpacke die Datei nicht und wähle nicht versehentlich eine andere
    ZIP-Datei.

### Der Import schlägt fehl

-   Starte CurseForge neu und versuche es erneut.
-   Lade die ZIP-Datei erneut herunter, falls sie beschädigt oder
    unvollständig sein könnte.
-   Prüfe, ob ausreichend Speicherplatz vorhanden ist.

### Minecraft startet nicht oder stürzt ab

-   Warte, bis CurseForge alle Dateien eingerichtet hat.
-   Stelle sicher, dass du das importierte FREUNDESCORD-Profil startest.
-   Verändere die Mod-Zusammenstellung nicht, wenn du mit dem Server
    spielen möchtest.
-   Sichere bei anhaltenden Problemen die relevanten Minecraft-Logs und
    notiere die Fehlermeldung.

### Ich kann dem Server nicht beitreten

-   Prüfe, ob du die richtige Adresse `5.175.177.15` eingegeben hast.
-   Stelle sicher, dass Minecraft mit dem FREUNDESCORD-Modpack gestartet
    wurde.
-   Kontrolliere, ob Modpack und Minecraft-Version mit der
    Server-Zusammenstellung übereinstimmen.
-   Wenn die Verbindung weiterhin fehlschlägt, frage die Serverleitung,
    ob der Server online ist.
